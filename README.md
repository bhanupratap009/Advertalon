# Marketing Website

This repository contains a full-stack marketing website with:

- Frontend: Next.js app in `frontend/`
- Backend: Laravel API in `backend/`

## Structure

- `frontend/` for marketing pages, components, services, and static assets
- `backend/` for API controllers, models, routes, and database structure

## Getting started

1. Install frontend dependencies in `frontend/`
2. Install backend dependencies in `backend/`
3. Copy env files and configure your application settings
4. Run the frontend and backend services separately

## Notes

This scaffold is intentionally minimal and ready for expansion with real content, CMS data, and booking flows.
